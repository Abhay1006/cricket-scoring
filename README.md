# 🏏 Cricket Scoring Pro

A modern, high-performance, real-time cricket scoring dashboard built for desktop and mobile devices. 

![Screenshot_20241120_164150](https://github.com/user-attachments/assets/6a66341f-3300-4adc-be4d-e8375c0c27ed)

## 🚀 Features

- **Modern UI/UX:** Sleek dark mode with vibrant neon accents and premium glassmorphism styling.
- **Dynamic Dashboard:** Real-time calculation of runs, wickets, overs, and extras.
- **Live Scorecards:** Interactive batting and bowling scorecards that update instantly.
- **Next.js 15 Powered:** Blazing fast performance built on the latest Next.js and React 19 architecture.
- **Secure:** Completely patched against recent React Server Components RCE vulnerabilities (CVE-2025-55182 & CVE-2025-66478).

## 🛠️ Tech Stack

- **Framework:** Next.js 15 (React 19)
- **Styling:** Custom Vanilla CSS with CSS Variables and Glassmorphism
- **Package Manager:** `pnpm` (for faster, secure dependency management)
- **Deployment:** Vercel

## 💻 Getting Started

First, make sure you have `pnpm` installed. Then, clone the repository and install the dependencies:

```bash
# Install dependencies
pnpm install

# Run the development server
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result. You can start editing the page by modifying `app/page.tsx` and the scoring dashboard in `components/AdminPanel.tsx`.
